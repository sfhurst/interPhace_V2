# noisePhace Button Map

## Build 300 — B2 Artifact engine

The old grid-based N1–N4 pattern architecture is retired from the forward plan. noisePhace becomes a continuous evolving bed instrument.

| Button | Page / Action | Planned controls |
|---|---|---|
| B1 | Noise | Color · Tone · Body · Air · Amount · Preset |
| B2 | Artifact / Surface | Character · Density · Size · Tone · Amount · Preset |
| B3 | Movement | Volume Motion · Density Motion · Color/Timbre Motion · Stereo Motion · Motion Speed · Preset |
| B4 | Space | Width · Delay · Reverb · Space Motion · Distance · Preset + LINK |
| B5 | Generate | Eventually chooses one curated preset from each B1–B4 page |
| B6 | Phace | interPhace Phace selector / shell navigation |

## B1 — Noise

One continuous spectral-noise engine covering broad useful noise colors rather than separate sequenced lanes.

- Color
- Tone
- Body
- Air
- Amount
- Preset

Target material includes white, pink, brown, green-like/shaped noise, air, deep noise floors, and other continuous spectra discovered during development.

## B2 — Artifact / Surface

Continuous-time stochastic event engine.

- Character
- Density
- Size
- Tone
- Amount
- Preset

Primary reference: convincing record/vinyl crackle and surface noise.

Additional territory: dust, ticks, pops, static flecks, granular debris, sparse crackle, electrical artifacts, rain-like micro-events, and related non-rhythmic material.

## B3 — Movement

Noise-native long-form evolution.

- Volume Motion
- Density Motion
- Color / Timbre Motion
- Stereo Motion
- Motion Speed
- Preset

Movement should support recede/return behavior, evolving artifact density, spectral withdrawal/return, internal stereo wandering, and asynchronous timescales.

## B4 — Space

Environment controls.

- Width
- Delay
- Reverb
- Space Motion
- Distance
- Preset
- LINK toggle associated with Space Motion

LINK Off uses noisePhace's own whole-field Space Motion.

LINK On joins the interPhace Drone/Noise relationship. Initial reference behavior is Build 285 Opposed Orbit: Drone and Noise occupy opposite sides of the same whole-field orbit while retaining independent source, Movement, Width, Delay, Reverb, and Distance settings.

## B5 — Generate

Future behavior only after B1–B4 preset banks are established.

Generate selects one named curated preset from each page:

`Continuous + Artifact + Movement + Space`

It does not directly roll raw sliders.

## Timing

noisePhace is not sequenced.

No pattern grid, musical bars, step timing, or tempo quantization. Artifact events use continuous stochastic timing. Local and global playback treat noisePhace as a free-running rendered bed.
